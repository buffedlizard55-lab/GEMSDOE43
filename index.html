What was tested

Independent geology, fixed baseline

Map-unit boundaries are not faults by default. The experiment asked whether contacts with different major lithology/age signatures, when coincident with a magnetic edge, add useful structure to an existing surface.

H46-B surface
blocked public-catalogue test

The auxiliary signal is unit-contact contrast multiplied by the empirical percentile of the smoothed TMI horizontal gradient. The frozen combination uses geometric-mean weights 0.75 for the H42 incumbent and 0.25 for contact evidence, with the registered 0.05 floor. No known-fault geometry, catalogue label, or prior submission pixel enters either prediction surface.

The labels were loaded only after the surfaces were built, for the fixed fold assignment, training-trace emission guard and public-catalogue DTI calculation. Four 20 km spatial folds used 40,000 predictions per fold and the same deterministic packing/DTI implementation for both arms.

Source audit

USGS SGMC coverage passed; score gate did not

Source availability and feature support were checked before the blocked proxy run.

Source gates passed
  • Official SGMC v1.1 CA/NV polygons plus same-release all-state tables; pinned bytes and SHA-256.
  • 100% mapped-unit coverage across 5,167,373 finite-footprint cells.
  • 96.3289% joint major-lithology and age-pair support.
  • 476,338 positive contact-contrast cells; zero outside-footprint values.
  • 12,469 intersecting geometries transformed; zero transform errors or rasterization warnings.
  • Only geol_poly components and Age/Lithology tables were extracted/opened; neither Structure layer was opened.
  • Version caveat: the official ScienceBase item now recommends a newer 2026 GeMS release (DOI 10.5066/P1A3DQZK). This frozen test used SGMC v1.1 and did not audit that newer release.
Promotion gate failed

H46-B's positive but small mean proxy delta and two fold wins fell short of the frozen threshold. The source gate answers “can this feature be constructed across the study footprint?” It does not answer “does it detect new faults?”
