What this submission is

The competition's distance-weighted Tversky index is, for a fixed number of emitted points, exactly the Maximal Covering Location Problem of Church & ReVelle (1974): place K facilities of service radius 300 m to maximise the demand covered. This repository solves that problem directly on a continuous probability surface with the submodular greedy algorithm, which carries a proven (1 − 1/e) ≈ 63.2 % worst-case guarantee against the true optimum — a formal floor that no hand-picked spacing constant has.

The second free parameter, the number of dots, is derived rather than swept. Because the index's denominator rises by exactly 0.2 per emitted dot whatever that dot's credit, a dot is worth emitting iff its marginal coverage exceeds 0.2 × DTI. Solving that condition self-consistently is a Dinkelbach fixed point, so there is no spacing constant and no magic budget anywhere in the pipeline.

Where the headroom is

The group's best artifact realises 0.126 weighted credit per emitted dot against a theoretical 3.0 for a dot sitting on a straight fault trace (1 + 2·(2/3) + 2·(1/3)) — about 4 %. The gap between 0.2778 and the top of the board is therefore not an emission-quality gap and not a spacing gap; it is a coverage gap, which is precisely what the covering formulation optimises.
