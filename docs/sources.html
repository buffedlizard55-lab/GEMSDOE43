H46 source audits · separate from validation

Official geology sources and version caveat

USGS · NGB

National Geochemical Database

The H46-A source-only audit assessed eligible in-footprint stream-sediment records and assay support. It failed the frozen sample-count gates (451 / 447), so no H46-A model or holdout score was run. The source metadata warns of coordinate uncertainty for some records.

USGS · SGMC v1.1

State geologic map compilation

H46-B pinned the published v1.1 CA/NV polygon components and same-release age/lithology tables. Polygon unit_link joined to the tables; source hash/coverage and schema reports are in the SGMC audit receipt. Passing these source checks did not make the candidate promotion gate pass.

USGS · newer release notice

2026 GeMS SGMC release

The USGS v1.1 catalog record recommends this newer GeMS release. It was not fetched, opened, or audited in the frozen H46-B experiment. It is not silently substituted for the pinned v1.1 source.

Complete source receipts: NGB, SGMC v1.1, and H46-B input manifest.
