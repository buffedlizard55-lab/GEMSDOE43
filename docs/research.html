The metric, verbatim

From the official problem description, “Performance metric”, read 2026-10-06:

k(d)  = max(1 - d/R, 0),                       R = 300 m
TP_w  = sum_{g in G} max_{x: d(x,g) <= R} p(x) k(d(x,g))
FP_w  = sum_{x: p(x) > 0} p(x) [1 - max_{g in G} k(d(x,g))]
FN_w  = sum_{g in G} [1 - max_{x: d(x,g) <= R} p(x) k(d(x,g))]
DTI   = TP_w / (TP_w + 0.2 FP_w + 0.8 FN_w + eps)

Implemented verbatim in src/gems43/metric.py, and tested against (i) the organizer's own worked example TP_w=3.00, FP_w=1.89, FN_w=2.00 → 0.60 and (ii) a brute-force O(N·M) re-derivation on random grids.

Three consequences, and what each one buys

#consequenceconsequence for the design
1FN_w = |G| − TP_w, so DTI = T / (0.2T + 0.2F + 0.8|G|) the index is a ratio of two set functions → fractional-programming tools apply
2Adding a pixel of weight p raises the denominator by exactly 0.2p whatever its credit, so the move pays iff k > 0.2·DTI — independent of p binary emission is optimal; the stopping rule needs no tuned threshold
3FP_w = |S| − Σ_i k_i is modular in the emitted set; under the disjoint-credit hypothesis the index reduces to T / (0.2|S| + 0.8|G|) for a fixed dot count, the problem is MCLP

Correction recorded as IR-43-007: the reduction in row 3 is a hypothesis, not a bound. It is pessimistic when several dots compete for the same truth pixel (the regime at K > |G|) and optimistic when there are fewer dots than truth pixels. It is reported as the reduction everywhere, never as a guaranteed score.

From MCLP to the emitted file

  1. Demand field. A per-pixel prior π(x) that a hidden fault occupies x, normalised so Σ π = |Ĝ| (12,226, the parent project's live-anchor estimate). That normalisation is what puts the marginal gains on the metric's own scale.
  2. Coverage objective. T(S) = Σ_x π(x)·max_{i∈S} k(d(i,x)) — weighted max-coverage, hence monotone submodular.
  3. Church–ReVelle greedy with exact residual bookkeeping. Unlike a textbook MCLP, coverage is a graded kernel, so the solver tracks max(0, k(δ) − C(x)) at every pixel and two overlapping facilities are credited only once. It is the exact greedy (not lazy): after each acceptance only the candidates within 600 m can have changed, so a full pass per iteration is unnecessary. Worst-case guarantee (1 − 1/e) = 0.6321.
  4. Cardinality by Dinkelbach fixed point. One greedy pass produces the whole marginal-gain path; the budget is where the marginal gain falls below 0.2·s, solved self-consistently. No spacing constant, no swept budget.
  5. Binary emission (p = 1 on the chosen dots), because consequence 2 makes p < 1 strictly dominated.
  6. Fail-closed write, then an independent re-read audit, then the near-duplicate screen.
