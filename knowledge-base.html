H46-A · source gates failed

USGS Northern Great Basin geochemistry

The U.S. Geological Survey's Multielement Geochemical Dataset of Surficial Materials for the Northern Great Basin, Open-File Report 2002-227, is documented in its data page, downloadable CSV, metadata and quality notes. The report motivates a regional hydrothermal-pathfinder hypothesis, but also identifies study/method/detection-limit variability and flags substituted results; the frozen method excluded censored/substituted assays.

The official CSV was retrieved and SHA-256 checked by the source audit, but spatial coverage was too sparse for the predeclared design: 451 eligible stream samples and 447 with at least three usable assays inside the footprint. The thresholds were 1,000 and 500. H46-A therefore stopped before scoring. This is not a judgment that regional stream geochemistry is scientifically uninformative; it is a decision that this source/method could not support the registered test.

Access irregularity: the final manual link-review request to the raw CSV URL returned HTTP 500, while the recorded Actions runner download previously succeeded (2,318,363 bytes; pinned SHA-256 in the amendment). This fetcher response does not establish general source unavailability; the verified runner receipt is the access evidence.

H46-B · source gates passed; promotion failed

USGS State Geologic Map Compilation (SGMC), version 1.1

The official SGMC state compilation page, metadata and data-release DOI 10.5066/F7WH2N65 describe a multi-state GIS compilation built from source maps at a range of scales. Its polygon field description is geol_poly; linked class tables are documented for age, lithology and units. USGS's credit guidance is linked for downstream reuse.

Version / recency caveat (checked 2026-10-06): the official 2017 SGMC v1.1 ScienceBase record now says the release was updated in 2026 with a newer GeMS version and recommends new USGS data release DOI 10.5066/P1A3DQZK (official NGMDB product record). This frozen experiment used the pinned v1.1 archives named in its preregistration; it did not download or audit the newer release. The new source is not silently substituted. Any follow-on work must audit that release and use fresh confirmation regions before considering a new candidate.

The official California archive and Nevada archive provide the relevant geol_poly polygons. The official same-release tables archive provides SGMC_Age.csv and SGMC_Lithology.csv. The join uses state plus unit_link; the class signature uses major-rank lith1 and a known (min_era, max_era) pair.

Audit irregularities and boundaries

  • The CA/NV state ZIPs do not include age.csv; age and lithology are in the separately listed, same-release all-state tables ZIP.
  • The official lithology table is named SGMC_Lithology.csv, not the loader's initial expectation lith.csv; that mismatch was corrected and tested.
  • Each state ZIP lists Structure-layer members. The final selective loader extracts and opens only the geology-polygon components and needed tables; neither Structure layer was opened or used.
  • The audit found EPSG:4326 declarations for CA/NV polygons and transformed 12,469 grid-intersecting geometries to EPSG:32611 with zero transform errors and zero rasterization warnings. It mapped all 5,167,373 finite-footprint cells, with 96.3289% joint major-lithology/age support, 476,338 positive-contact cells and zero outside-footprint signal.
  • SGMC metadata warns that source-map scale varies and state map units are not reconciled across boundaries. The feature is a map-unit contact proxy—not a fault inventory.

The source-only audit read neither labels nor sample-template pixel values. It established constructibility only. Full receipts: checked-in audit JSON, dated source/table amendment and Actions run 37455479306.

H46-C · not tested

Landsat Collection 2 surface reflectance

The USGS Landsat Collection 2 page describes global Level-2 surface-reflectance products and no-cost USGS data access. Availability at program level does not verify exact cloud-free scene coverage, suitability for a regional persistent-alteration composite, or reuse/competition-sharing terms for a particular derived raster. Those gates remain open, and no Landsat product was retrieved for this project.

Preregistered comparison

Incumbent, folds and decision rule

Same labels, masks, prediction mass, spacing and DTI implementation for both arms.

Defined incumbent

H42 SH_basin_strong|sep4.0|N40000, recomputed from the pinned feature and USGS 3DEP-derived LiDAR-scarp input. The registered historical four-fold DTI is 0.242272, 0.247658, 0.255021 and 0.258025 (mean 0.250744). The same-run baseline was required to reproduce each fold within 1e-5; all four values matched exactly.

H46-B's fixed feature is the four-neighbour map-unit boundary contrast from major lith1 and age-pair differences, multiplied by the empirical TMI horizontal-gradient percentile. Its surface is combined with the unchanged H42 surface using fixed 0.75 / 0.25 geometric-mean weights and a 0.05 floor. No labels, known-fault lines, or sibling prediction raster enter either surface.

Blocked design and limits

Fold assignment: ((row // 200) + 2 * (col // 200)) % 4, corresponding to four-colour 20 km blocks on the 100 m grid. Each fold emits 40,000 predictions with 400 m minimum spacing, a 300 m fold-edge exclusion and a two-pixel training-trace guard.

Labels are used only for fold assignment, the predeclared emission guard and DTI scoring after the prediction surfaces have been built. The scored positives are the public catalogue, so this measures catalogue transfer to held blocks—not success on the private challenge's new-fault test set.
