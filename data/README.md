# Local input data

Place the competition files in this directory by running `bash scripts/download_competition_data.sh`. The script restores hash-pinned, owner-published mirrors through the GitHub CLI; this is **not** an authenticated DrivenData download and the pins prove mirror consistency, not organizer provenance. The official competition data page requires DrivenData login. See `registry/data_sources.json` and `research/data_access.md` for the exact source paths, hashes, and limitations.

Raw rasters, private challenge labels, credentials and runner scratch files are git-ignored and must not be committed. The H46-B source audit used the official SGMC v1.1 CA/NV `geol_poly` components and the same-release Age/Lithology CSV archive, pinned by `scripts/download_sgmc.sh`; see `evidence/sgmc_source_audit.json` and `research/AMENDMENT-2026-10-06-SGMC-table-archive.md`. Neither Structure layer was opened. A newer 2026 GeMS release is now recommended by the USGS catalog; it was not downloaded/audited for H46-B.

The pinned owner-mirrored sample template, features, public-catalogue labels and LiDAR are restored with `scripts/download_inputs.sh`. Their exact paths, byte counts, SHA-256 values and provenance caveats from the blocked proxy run are in `evidence/h46b/data_manifest.json`. The template is used only for its grid/finite mask; public-catalogue labels are used only for the registered fold, emission guard and local proxy DTI. Private challenge labels were not accessed.

**No candidate currently passes the promotion gate.** The H46-B runner generated a unique GeoTIFF, but it failed the preregistered mean/win thresholds; the file is removed from the current tree and not linked from the current project site. An earlier branch commit and unexpired GitHub Actions artifact still contain it; a deletion request returned HTTP 403 because the GitHub integration lacks permission. The runner receipt and access caveat are in `evidence/h46b/submission_receipt.json` and `evidence/h46b/publication_status.json`. Do not download or submit the historical file, and do not place raw inputs or scratch products in `docs/downloads/`; only a future candidate that passes all registered holdout, novelty, provenance, format and rules gates may be offered there.
